##  三、各组对接任务

### 3.1 前端组

**任务**：
- 对接已完成接口，参考 `API.md` 开发页面
- 需认证接口需在请求头携带：`Authorization: Bearer {token}`

**调用示例**：
```javascript
// 登录获取token
const loginRes = await fetch('http://localhost:8080/user/login', {
  method: 'POST',
  headers: { 'Content-Type': 'application/x-www-form-urlencoded' },
  body: 'username=张三&password=123456'
});
const { data } = await loginRes.json();
const token = data.token;

// 带token请求用户信息
const res = await fetch('http://localhost:8080/user/info/1', {
  headers: { 'Authorization': `Bearer ${token}` }
});

```

|------|----------|----------|

| 认证 | token 过期访问 | 返回 401，提示 token 已过期 |
| 异常 | 请求参数缺失 | 返回错误提示 |
| 异常 | 请求方法错误 | 返回 405，提示方法不支持 |
| 异常 | 接口路径错误 | 返回 404，提示接口不存在 |

**部署环境要求**：
- JDK 17 或更高版本
- MySQL 8.0 或更高版本
- 云服务器（建议 2核4G 及以上配置）

**部署步骤**：
1. 服务器安装 JDK 17 和 MySQL
2. 导入数据库脚本
3. 修改 `application.yml` 中的数据库连接配置
4. 打包项目：`mvn clean package`
5. 运行 jar 包：`java -jar target/luopan-0.0.1-SNAPSHOT.jar`
